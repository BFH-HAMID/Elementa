# Honours content coverage (editorial audit)

This audit covers **the entire Honours content directory**, including entries that predated this branch. Run `npm run check:honours` to re-check content relationships.

| Type | Entries | Checked |
| --- | ---: | --- |
| Equations | 82 | Headline formula, bilingual explanation, at least two derivation steps, topic quiz, experimental-context note |
| Practical guides | 64 | Aim, apparatus, theory, procedure, observation table, calculation, precautions, error sources, viva and topic quiz in both languages |
| Equations with linked practicals | 37 | Linked experiment slug resolves (including relevant HSC labs) |
| Equations **without** a linked practical | 45 | Experimental context explicitly says when a direct test needs specialist equipment, or that no direct lab is supplied |

**What this check does not establish:** It does not certify that every derivation is exhaustive, that every variable is correctly described, that every example has been independently peer-reviewed, or that an experiment exists for every abstract result. A related practical may test an observable *implication*, rather than prove a general theoretical law. For example, an optical grating can measure hydrogen emission lines with a suitable source but cannot directly observe a Bohr orbit. Spectroscopic and high-energy tests must not be replaced by unrelated classroom experiments just to fill a checklist.

The original request covers 300 distinct topics. This branch is still **incomplete** against that full scope. Before calling the collection complete, review the remaining topic inventory against the original list, expand short two-step derivations where necessary, commission specialist practicals where safe and feasible, and obtain subject-teacher review of scientific and Bengali wording.
